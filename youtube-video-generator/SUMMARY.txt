USAGE EXAMPLES
================================================================================

1. Create a Scene:
   const manager = new SceneManager();
   manager.addScene({
     title: 'Welcome',
     voiceoverDuration: 3,
     transitionDuration: 0.6
   });

2. Draw Animation:
   drawSlam(ctx, "Key Point", W/2, H/2, 0, 0.5, {
     typography: 'headline',
     color: C.accent,
     glow: { color: C.accent }
   })(t);

3. Add Caption:
   captionRenderer.addCaption(0, 3, 'Important message', ['Important']);
   captionRenderer.render(ctx, t);

4. Apply Camera:
   const cam = camera(t, punches, shakes, pushes);
   applyCam(ctx, cam);

5. Finish with Shaders:
   finishing(ctx, t, lightLeaks, flashes);
