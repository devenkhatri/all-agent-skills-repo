# assets/

Drop your media here and reference it from `../index.html`:

- `clip_cut.mp4` — your already-cut talking-head video (the A-roll)
- `screenshot.png` — any real screenshot you want framed in a glass card
- `fonts/` + `fonts.css` — the bundled Newsreader + Schibsted Grotesk web fonts (already here)

Hyperframes bakes whatever is referenced here into the render. Keep screenshots at
1200px or wider so they stay sharp over the vertical video.
